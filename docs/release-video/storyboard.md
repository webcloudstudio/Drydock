# Drydock Product Announcement Storyboard

## Visual Contract

- Format: 1920x1080 MP4.
- Style: clean 2D technical cartoon, professional free-software launch.
- Palette: white, steel blue, dark navy, bright green, amber command highlights.
- Motion grammar: documents move left-to-right on a conveyor; command buttons trigger transformation; structured artifacts exit the machine.
- Audio: female neural voice, light generated technical ditty beneath it.

## Scenes

| Time | Visual | Voice |
|---:|---|---|
| 0-5 | Logo reveal, title, subtle machine grid. | Meet Drydock. |
| 5-12 | Idea/specification papers flow into conveyor. | Ask your LLM to write your idea as a specification. |
| 12-20 | Button press: `drydock analyze`; cards exit as Stories, Questions, Blockers, Acceptance Criteria. | Drydock imports and analyzes. |
| 20-29 | Button press: `drydock plan`; Blueprint sheets and Manifest blocks appear. | Blueprints and Manifest. |
| 29-39 | Manifest blocks arrange into a dependency graph; unidentified blocks are nudged into order. | Executable build graph. |
| 39-49 | Button press: `drydock build`; code window and Tests Passing indicator. | Working software with TDD evidence. |
| 49-57 | New requirement paper arrives; `drydock refit` updates Manifest and feeds build again. | Change loop stays aligned. |
| 57-64 | CTA with logo: Stable Alpha, MIT Licensed, Contributors Wanted, WebCloudStudio.com. | Take it for a sail. |

## Music Options

The renderer produces three generated beds in `audio/`:

- `music_option_1_clean_pulse.wav` - restrained technical pulse.
- `music_option_2_bright_ditty.wav` - more energetic product-announcement rhythm.
- `music_option_3_minimal_drive.wav` - steady understated forward motion.

The first MP4 cut uses option 2 by default.
