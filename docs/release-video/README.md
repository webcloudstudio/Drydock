# Editing the Drydock Release Video

The video is generated by `make_release_video.py`. All timing follows the
narration: voice synthesis records the moment each command is spoken to
`audio/narration_marks.json`, and every machine, headline, and wall panel is
anchored to those marks.

## Build it

Run from `docs/release-video/`:

```bash
uv run --python 3.12 --with edge-tts --with imageio-ffmpeg --with numpy --with pillow \
  python make_release_video.py            # full pipeline -> renders/drydock-announcement-first-cut.mp4
```

Faster loops (same `uv run ...` prefix):

```bash
python make_release_video.py --stills     # only review PNGs in renders/stills/ (seconds)
python make_release_video.py --no-voice   # full MP4 but reuse the existing voice + marks
```

Re-synthesize the voice (drops `--no-voice`) only when you change
`voiceover_script.txt`. Editing constants or labels does not need new voice.

## Move a machine earlier or later

Edit `MARK_OFFSETS` near the top of `make_release_video.py`. Each entry nudges
that beat — the machine, its headline, and its wall panel move together.

```python
MARK_OFFSETS = {
    "analyze": -1.5,   # negative = earlier ("back"); positive = later
    "plan": -5.0,
    "manifest": -3.0,
}
```

- Keys: `import`, `analyze`, `plan`, `manifest`, `quarterdeck`, `build`,
  `refit`, `truths`, `cta`.
- Units are seconds. `-4.0` moves that beat 4 seconds earlier; `+2.0` moves it
  2 seconds later. Omit a key (or set `0.0`) to leave it on its spoken word.

**Spacing limit.** A machine cannot be pulled so far that it lands on its
neighbor. Two machines need about 2.4 s of separation or their gantries
overlap on screen. The spoken gaps are roughly: import→analyze 5.4 s,
analyze→plan 8.7 s, plan→build 32 s, build→refit 10.6 s. Pulling `analyze`
back 4 s leaves only 1.4 s and it collides into `import`; about `-1.5` is the
practical limit there.

After editing, re-render:

```bash
uv run --python 3.12 --with edge-tts --with imageio-ffmpeg --with numpy --with pillow \
  python make_release_video.py --stills --no-voice   # eyeball first
```

## Rename on-screen labels

| Label | Where |
|---|---|
| QuarterDeck block cards ("Story") | `block_tile()` — the `draw.text(..., "Story", ...)` call |
| QuarterDeck block names (Foundation, Persistence, …) | `draw_qd_panel()` — the `blocks = [...]` list |
| Manifest panel cards (Stack, Rigging, Story 1–3) | `draw_manifest_panel()` |
| Belt Blueprints card sections (Behavior/Acceptance/Guardrails) | `Timeline.__init__` — the Blueprints `card(...)` `sections=` list |
| Section headlines ("Analyze is Agile Planning", …) | `Timeline.__init__` — the `self.scenes = [...]` list, 4th field per row |

## Other tunables (top of the file)

| Constant | Effect |
|---|---|
| `CONVERT_OFFSET` (0.35) | Seconds after the word that the machine finishes converting its lead card |
| `RIDE_IN` (3.4) | Seconds an input rides the belt before it reaches its machine |
| `SENTENCE_GAP` / `PARAGRAPH_GAP` | Silence inserted between sentences / paragraphs |
| `V` (220) | Belt speed in px/s |

Change what is said, or insert a `[pause 1.5]` line, in `voiceover_script.txt`.
