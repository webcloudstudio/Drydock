I am pleased to announce a new Drydock **version 0.8 Beta**. Couple of major features:

- Full **Acceptance Criteria Testing Framework.** Measured Self correcting Acceptance Criteria define the Definition of Done.
- **Full UAT Harness.** 10 projects, scored on Haiku and Luna to test Drydock.
- **Developer Notes And Skills** including memory files for each
- **Language Support** for **Python and Go** - easy extensibility via specific markdown
- **Encapsulated Persistence** for **SQLite and PostgreSQL** - easy extensibility via specific markdown
- **Diagnosis and Repair Loop** root cause analysis, Blueprints iteration, rebuild
- **Model choice and traceability: Claude, Codex, Gemini.**

## Drydock workflow

Build, verify, diagnose, repair — up to five attempts. For an analyzed and planned Target:

```bash
for attempt in {1..5}; do
    drydock status MyApp --check && break
    if drydock status MyApp --ready; then
        drydock build MyApp && continue
    fi
    drydock diagnose MyApp --apply || break
done
drydock status MyApp --check
```
