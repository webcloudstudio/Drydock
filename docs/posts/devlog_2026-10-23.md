### What is Drydock
  * Build Software from Your Specifications using low end models (Haiku 5.5, Luna, or Gemini). <br>
  * Based on **Agile Decomposition** and **Test Driven Development**.
---
### **New Feature: Measured, self-correcting acceptance criteria**.
  * `drydock plan repair` measures, categorizes, and corrects acceptance criteria
### **New Feature: Self Improving Builds**
  * `drydock diagnose` reads failed runs, identifies the root cause, and proposes corrections. 
### **New Feature: Encapsulated Persistence Layer**
  * `DATABASE.md` uses pre-built native library plus named sql operations to minimize change impact radius  
### **New Feature: Updated Drydock workflow**
  * `drydock_runner.sh` is the minimal self repairing mechanism to build
```bash
drydock init MyApp                            # create the workspace
drydock import MyApp "$INPUT_DIRECTORY"       # load your specifications
drydock analyze MyApp                         # create stories, questions, blockers
drydock plan MyApp                            # create Blueprints and Manifest
drydock plan verify MyApp || drydock plan repair MyApp  # repair/validate acceptance criteria

# implement build as a self repairing loop
n=1; max=5
while drydock status MyApp --ready
do
    echo "*** BUILD ATTEMPT $n ***"
    drydock build MyApp || drydock diagnose MyApp --apply
    n=$((n+1))
    if [ "$n" -gt "$max" ]
    then
        echo "hit $max build attempts - aborting"
        exit 1
    fi
done
drydock status MyApp --check                  # done when every block is closed
drydock score release MyApp                   # does project meet its AC
```
