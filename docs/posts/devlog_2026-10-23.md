## **Build Anything From Specifications** with Haiku 5.5, Luna, or Gemini

Drydock is a full featured software builder for specifications that uses Agile Plannign and Test Driven Development to deliver big specifications with cheap models and to maintain them once built. 

- **Measured, self-correcting acceptance criteria** define your **Definition of Done**.
- **Self Improving Builds**
  * `drydock diagnose`** reads a failed run, identifies the root cause, and proposes Blueprint corrections. 
- **Python, Go, SQLite, and PostgreSQL** - its easy to expand this list.
- **Encapsulated Persistence Layer**
  * `DATABASE.md` uses pre-built native library plus named operations. Contract change detection identifies blueprints needing rebuild. Encapsulation minimizes change impact radius  
- **Updated Drydock workflow**

Basic project build loop, including acceptance-criteria verification and repair:

```bash
drydock init MyApp                            # create the workspace
drydock import MyApp "$INPUT_DIRECTORY"       # load specifications
drydock analyze MyApp                         # stories, questions, blockers
drydock plan MyApp                            # Blueprints and Manifest
drydock plan verify MyApp || drydock plan repair MyApp  # repair acceptance criteria

n=1; max=5
while drydock status MyApp --ready
do
    echo "*** BUILD ATTEMPT $n ***"
    drydock build MyApp || drydock diagnose MyApp --apply
    n=$((n+1))
    if [ "$n" -gt "$max" ]
    then
        echo "hit $max build attempts - aborting"
        exit 1
    fi
done
drydock status MyApp --check                  # done when every block is closed
drydock score release MyApp                   # release gate
```
