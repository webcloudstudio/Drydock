## Goal

Build QuarterDeck the correct way: screens are shown based on where the project is in the
delivery workflow, not unconditionally. Build analyze to produce the correct set of artifacts.

## Decisions

### QuarterDeck Architecture
- `init` seeds `console.yaml` with all screens pre-declared upfront.
- QuarterDeck hides sidebar items whose backing file does not exist — no placeholder, no screen.
  Visibility is driven entirely by file existence; no runtime console.yaml rewrites.
- Variable spikes auto-surface via a `sources:` glob on `QuarterDeck/questionnaires/`.
- `command_status` (Acceptance Status) removed from the target QuarterDeck template — it is
  Drydock-dev-repo specific and duplicates Soundings for a target project.

### COMPASS.md
- IMPLEMENTED. COMPASS.md lives at target root (`COMPASS.md`). Injected into every LLM run.
  Generated by `analyze` if absent. `import --format intent` places it at target root.

### Sea Trials
- LLM-generated by `analyze` from the spec — not human-authored.
- High-level strategic objectives; what "done" looks like at product level.

### Soundings
- AC blocks derived from the spec by `analyze`, not by `plan create`.

### Analyze: Single LLM call, multiple output blocks
- One LLM call produces all analyze outputs via delimited blocks (extends current `=== ANALYSIS.md ===`
  pattern). Token-efficient; parser writes each file deterministically.

## Analyze Output Contract

| Output | Location | LLM analytical goal |
|---|---|---|
| COMPASS.md | `COMPASS.md` (target root) | Constitution/system prompt — generated if absent |
| ANALYSIS.md | `QuarterDeck/planning/ANALYSIS.md` | Narrative gap and coverage report |
| SEA_TRIALS.md | `SEA_TRIALS.md` | High-level strategic objectives |
| SOUNDINGS.md | `SOUNDINGS.md` | AC blocks projected from the spec |
| Intent spike | `QuarterDeck/questionnaires/spike-intent.json` | What is this product trying to do? |
| Stack spike | `QuarterDeck/questionnaires/spike-stack.json` | What tech is implied? (Rigging options) |
| Gaps + AC spike | `QuarterDeck/questionnaires/spike-gaps-ac.json` | Where is the spec incomplete; what AC is missing? |
| Guardrails spike | `QuarterDeck/questionnaires/spike-guardrails.json` | Constraints: security, compliance, scale, performance |
| Variable spikes | `QuarterDeck/questionnaires/spike-<slug>.json` | Additional open questions discovered |

Does NOT touch: `BUILD_PLAN.md`, `tickets.json`, `console.yaml`.

## Spike Contract

- Each spike = one questionnaire file + one spike story in the plan structure.
- Each has a specific LLM analytical goal, not a generic question dump.
- Fixed four (intent, stack, gaps+ac, guardrails) always created.
- Additional spikes configurable via Rigging or analyze config.
- Commands cannot ask questions interactively — spike answers consumed by `plan create`.

## Workflow Stage Detection

Workflow stage is detected by artifact existence, not command history.

| Stage | Detection artifact |
|---|---|
| 1 — Initialized | `METADATA.md` exists |
| 2 — Blueprint imported | `blueprint/sources/.drydock-import` exists |
| 3 — Analyzed | `QuarterDeck/planning/ANALYSIS.md` exists |
| 4 — Plan drafted | `BUILD_PLAN.md` exists with `state: draft` |
| 5 — Plan approved | `BUILD_PLAN.md` has `state: approved` |

## Acceptance Criteria

- QuarterDeck hides items whose file is absent; shows them automatically once the file exists.
- `analyze` produces the full output set in one LLM call.
- Fixed four spikes always created; variable spikes auto-discovered via `sources:` glob.

## Guardrails

- No console.yaml rewrites at runtime by any command.
- `plan create` is the assembly step; it consumes analyze outputs + answered spikes.
