## Purpose

Short pieces Ed posts on his page — announcements, ideas, build notes. Same calm, technical,
confident brand; written to be skimmed.

## Format (first pass)

| Aspect | Rule |
|--------|------|
| Length | Short. Lead with the point in the first line; one idea per post. |
| Structure | Hook → the idea → why it matters → optional link. No filler, no throat-clearing. |
| Tone | Technical peer, not marketing hype. Formal English; concrete over abstract. |
| Image | Optional. If used, match the Slate brand (dark chrome / light content); reuse project imagery where relevant. |
| Tags / hashtags | _(Ed to define a standard set.)_ |
