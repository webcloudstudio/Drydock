# CommonMark

A standalone stdin-to-stdout parser that converts CommonMark 0.31.2 Markdown into HTML.

## Intent

CommonMark is a standalone executable filter that reads CommonMark 0.31.2 Markdown from standard
input and writes the corresponding HTML to standard output. The project prioritizes specification
fidelity across block structure, inline structure, links, images, autolinks, raw HTML, and the
supplied conformance harness contract.
